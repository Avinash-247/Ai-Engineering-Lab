# AI Engineering Lab

> A hands-on engineering workspace for building, experimenting with, and understanding modern AI applications.

## Overview

**AI Engineering Lab** is a collection of practical projects, experiments, and implementations developed while exploring the foundations of modern AI engineering.

The repository focuses on turning concepts into working systems — from **LLM applications and Retrieval-Augmented Generation (RAG)** to **AI agents, backend APIs, vector databases, and AI workflows**.

Rather than being a single application, this repository serves as an evolving engineering workspace where different concepts are implemented, tested, debugged, and refined.

---

## Focus Areas

- **Generative AI & LLM Applications**
- **Retrieval-Augmented Generation (RAG)**
- **AI Agents & Tool Calling**
- **LangChain & LangGraph**
- **Prompt Engineering**
- **Embeddings & Vector Search**
- **Vector Databases**
- **REST APIs & Backend Development**
- **FastAPI**
- **Database Integration**
- **AI Application Workflows**
